First paid campaign checklist

Do not take a client until every item below is true on the production site.

  1. Production is running this branch, or the equivalent fixes are deployed. Currently unverified.
  2. Only the founder can open Studio. Public signup does not grant production access.
  3. Client originals are in a private bucket. The published link cannot fetch them.
  4. Job rerun updates the existing nif_files row instead of colliding. Code is on this branch.
  5. A failed reconstruction is labelled. Synthetic poses are not delivered as a capture.
  6. A published viewer link is the delivery. Test it on a phone before promising mobile.
  7. Founder desk records leads, clients, projects, quotes. Stored in this browser until a schema is approved.
  8. Studio can load a GLB, open a demo cooler, and drop a bottle. Browser acceptance still required.
  9. Backup and restore have been tried once.
  10. The public site no longer sells a social platform. Copy is updated on this branch only.
